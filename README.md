# Game Changer Cyber Intelligent Solution website

A responsive static website built with HTML/CSS and the photographs supplied in the two ZIP archives.

## Preview locally
Open `index.html` in a modern browser.

## Before publishing
1. Replace the contact placeholders in the Contact section of `index.html` with the company's official email, phone/WhatsApp number, and social links.
2. Review all photos and remove any that should not be public.
3. Confirm the service descriptions accurately reflect the services the company offers.

## Publish with GitHub Pages
1. Create a public GitHub repository named `game-changer-cyber`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. After GitHub finishes building, the site will be available at `https://YOUR-GITHUB-USERNAME.github.io/game-changer-cyber/`.

The logo is an editable SVG at `assets/game-changer-logo.svg`.
